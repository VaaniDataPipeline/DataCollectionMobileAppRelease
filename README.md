# Vaani Data Collection App

Android app for collecting audio data in Indian languages. Field workers use this app to register speakers and record audio across spontaneous, read-aloud, and conversational modes.

## Download

Latest APK: [Releases](https://github.com/VaaniDataPipeline/DataCollectionMobileAppRelease/releases/latest)

Install directly on Android — no Play Store required. Enable **Install from unknown sources** in device settings before installing.

## Requirements

- Android 7.0 (API 24) or higher
- ~50 MB storage minimum (more for cached images and recordings)
- Internet connection for initial sync and upload (offline recording supported)

## Installation

1. Download `VaaniDataCollection.apk` from the latest release
2. Open the file on your Android device
3. Tap **Install** and follow prompts

## Usage

Two roles:

| Role | Capability |
|---|---|
| **User** | Record audio for assigned images |
| **Contributor** | Register speakers + sync recordings to server |

Contributors log in with credentials provided by the admin. Users are registered on-device by contributors.

## Recording Modes

| Mode | Description |
|---|---|
| **Spontaneous** | Describe an image freely |
| **Read** | Read displayed text aloud |
| **Conversational** | Respond to a bot audio prompt |
